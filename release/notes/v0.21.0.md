## Screenshots, Stabilized Mirror, and App Navigation

Capture full-resolution screenshots, open a stabilized desktop mirror, and find settings faster in the reorganized sidebar. This release also improves Frame Generation's Auto rate, shader flow, and Turbo recovery.

### Changes

- <strong>Capture & Mirror</strong>
  - <strong>Screenshots.</strong> Assign a keyboard or device binding to save one or both eyes as full-resolution PNGs in Direct3D 11 and Direct3D 12 games. VectorXR saves files in the background.
  - <strong>Stabilized Mirror.</strong> Smooth head rotation in a desktop window for streaming, recording, or a spectator display. The headset view stays the same. The mirror supports Direct3D 11, Direct3D 12, and Vulkan. Enable it before launching a Vulkan game.
  - <strong>Mirror and screenshots with Quadviews.</strong> Where the runtime or Frame Generation composes quad views, the mirror and screenshots now draw the sharp focus view over the surrounding view in Direct3D 11 games.
  - A mirror window that fills a monitor lets mouse clicks pass through to the game. Screenshots taken in quick succession are saved instead of refused.
- <strong>App</strong>
  - <strong>Grouped sidebar.</strong> Capture & Mirror has separate pages for each utility. Registry and Discovery have their own pages under Applications. The sidebar remembers which groups you collapse.
  - <strong>Guides.</strong> Both capture utilities include walkthroughs with optional music.
- <strong>Frame Generation</strong>
  - <strong>Lowest rate for Auto.</strong> With Fixed Auto, set Lowest rate to 2x to keep Frame Generation on for games that run just under the refresh rate and stutter each time it stands by.
  - Auto resets when Frame Generation is turned back on, ignores frames from loading screens and mode switches, engages below 90% of the refresh rate, and accounts for GPU time before trying full rate.
  - Shader flow shows fewer stray specks in flat areas such as sky and water. The default Artifact suppression is now 10.
  - When the runtime holds frames to half rate, the On-Screen Display names the setting to turn off (for example, Smart Smoothing in Pimax Play) and when Frame Generation tries again. Auto falls back from hardware flow only when the flow itself runs late.
- <strong>Fixes</strong>
  - Frame Generation retries output images that the runtime is slow to return and presents complete image sets. Deferred swapchain work is bounded during game image acquisition.
  - Turbo preserves timing across mode handoffs. The Quadviews overlay stays off when the game began the session in stereo.
  - Direct3D 11 rendering and copies run independently of the game’s conditional rendering state. Imported network paths for screenshots and binding sounds are cleared and listed in the preview.
  - Settings the app does not recognize, such as those a newer version wrote, are kept when you save. The log names the VectorXR edition and version at the top.
  - Fixed a race between waits on the Direct3D 12 queue, and the app keeps Artifact suppression and Motion limit in range when it saves, so a hand-edited value cannot make the layer reject the settings file.
