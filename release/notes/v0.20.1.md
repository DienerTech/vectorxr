# VectorXR 0.20.1 - Draft: Fixes for PimaxXR, OpenXR Toolkit and Frame Generation

Draft notes, to be rewritten before release. A fix release for 0.20.0: Frame Generation no longer stalls games on PimaxXR, VectorXR works beside OpenXR Toolkit and Quad-Views-Foveated in more setups, and Pivot follows a Pimax recenter.

## Frame Generation

- **No more stalls on PimaxXR.** With Frame Generation engaged, PimaxXR's end of frame could block the game's own swapchain calls for most of a refresh; in DCS the frame rate fell from about 37 to 17 fps. Frame Generation now times that call so the game is not held up.
- **Frame Generation stays off when OpenXR Toolkit is below VectorXR,** where Toolkit cannot handle Frame Generation's extra frames.

## Compatibility

- **Games start with OpenXR Toolkit or Quad-Views-Foveated on VIVE runtimes.** Their probe instance no longer makes VectorXR refuse the game's own.
- **Turbo stands aside when OpenXR Toolkit's Turbo runs above VectorXR,** instead of pipelining frames twice.

## Pimax

- **Eye-tracked foveation is no longer switched off** in native quad views with eye tracking.
- **DCS's focus views stay aligned** on PimaxXR's native quad views.
- **Pivot follows a Pimax recenter,** which PimaxXR does without telling the game.
