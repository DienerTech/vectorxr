# VectorXR 0.20.2 - Guides, and Crash Fixes for Virtual Desktop and DLSS 5 Mods

A fix release for 0.20.1. A new Guides page explains what each part of VectorXR does, how to turn it on for a game, and how to turn it off again. Games no longer crash when they start VR again after leaving it, as MSFS 2024 did on Virtual Desktop, and games start with Cheeky's Foveated DLSS mod installed.

## Guides

- **A new Guides page** in the sidebar has a short guide to each enhancement and the On-Screen Display: what it does, when it helps, how to turn it on for a game, how to check that it's working, and how to turn it off.
- **Start here.** **What is VectorXR?** explains the app and the layer, how VectorXR decides what to apply to a game, and every way to turn it off. A second guide covers online games and anti-cheat.
- **Animated walkthroughs** step through each feature, with optional music that starts muted.
- **Read the guide** on each enhancement's page opens its guide, and **Back** returns to the page.
- **In every app language.**

## Fixes

- **No crash when a game starts VR again.** A game that left VR and went back in could crash to the desktop, as MSFS 2024 did on Virtual Desktop. This came in with 0.20.1.
- **Games start with Cheeky's Foveated DLSS mod.** Its OpenXR layer asks for functions before the game has started OpenXR, and a game crashed at startup when that layer was above VectorXR.
- **Clearer logs beside DLSS 5 mods.** The log names Cheeky's OpenXR layer and whether it's above or below VectorXR. When it's above, it takes the game's quad-views request for its own quad views, and the Quadviews line in the log now says so.

## Known issues

- In helicopters, Interpolate can show artifacts around the rotors and in the sky behind them.
- On Varjo headsets with Quadviews, focus sharpening is off in DCS while Frame Generation runs.
- On Varjo headsets with Quadviews, overlays such as OpenKneeboard are drawn at the Peripheral resolution outside the focus area, and can look jagged there at low Peripheral settings. Raise Peripheral (1.0 matches Varjo's default) if overlays matter more than the performance gain.
- Turbo prevents runtime reprojection such as SteamVR Motion Smoothing from working. Use one or the other.
