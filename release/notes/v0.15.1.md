## Eye Tracking Compatibility Fix

Restores Quadviews eye tracking in actionless OpenXR applications when hand-tracking or other API layers are active.

### Changes

- <strong>Eye tracking compatibility</strong>
  - Attaches VectorXR's private eye-gaze action set after a short grace period when an application, such as DCS, does not use the OpenXR action system itself.
  - Preserves application and third-party layer action sets when the normal attachment path is used, while preventing a second irreversible session attachment.
  - Adds a deterministic action-set harness covering actionless applications, late application attachment, missing resources, runtime rejection, and duplicate-attachment prevention.
