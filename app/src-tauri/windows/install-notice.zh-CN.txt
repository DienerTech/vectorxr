安装 VectorXR 之前

VectorXR 是一个 OpenXR API 层。启用后，它会加载到您运行的每个 OpenXR 游戏中，并处理在游戏与头显运行时之间传递的帧和调用。它不会读取或更改游戏的内存或代码。

在带有反作弊系统的在线游戏中使用 VectorXR 的风险由您自行承担，其中包括您的游戏账户。每款游戏的开发者决定其反作弊系统允许什么，并可随时更改，且没有任何游戏开发者认可 VectorXR。

请将 VectorXR 的问题报告给 VectorXR，而不是游戏开发者。
