安裝 VectorXR 之前

VectorXR 是一個 OpenXR API 層。啟用後，它會載入您執行的每一款 OpenXR 遊戲，並處理在遊戲與頭戴式裝置執行階段之間傳遞的影格與呼叫。它不會讀取或變更遊戲的記憶體或程式碼。

在具有反作弊系統的線上遊戲中使用 VectorXR 的風險由您自行承擔，包括您的遊戲帳號。每款遊戲的開發商決定其反作弊系統允許哪些行為，並可隨時變更，且沒有任何遊戲開發商認可 VectorXR。

請將 VectorXR 的問題回報給 VectorXR，而非遊戲開發商。
