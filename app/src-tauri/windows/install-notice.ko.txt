VectorXR을 설치하기 전에

VectorXR은 OpenXR API 레이어입니다. 활성화되어 있는 동안 실행하는 모든 OpenXR 게임에 로드되며, 게임과 헤드셋 런타임 사이를 오가는 프레임과 호출을 처리합니다. 게임의 메모리나 코드를 읽거나 변경하지 않습니다.

안티치트가 있는 온라인 게임에서 VectorXR을 사용하는 것은 게임 계정을 포함하여 사용자 본인의 책임입니다. 각 게임의 개발사가 안티치트에서 허용하는 범위를 정하며 언제든지 변경할 수 있고, VectorXR을 승인한 게임 개발사는 없습니다.

VectorXR 관련 문제는 게임 개발사가 아닌 VectorXR에 보고하십시오.
