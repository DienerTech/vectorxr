VectorXR をインストールする前に

VectorXR は OpenXR API レイヤーです。有効にしている間は、実行するすべての OpenXR ゲームに読み込まれ、ゲームとヘッドセットのランタイムの間でやり取りされるフレームと呼び出しを処理します。ゲームのメモリやコードを読み取ったり変更したりすることはありません。

アンチチートを備えたオンラインゲームで VectorXR を使用する場合は、ゲームアカウントを含め、ご自身の責任で行ってください。アンチチートで何が許可されるかは各ゲームの開発者が決定し、いつでも変更される可能性があります。また、VectorXR を承認しているゲーム開発者はいません。

VectorXR の問題は、ゲームの開発者ではなく VectorXR に報告してください。
